# Code of conduct

Discuss the work respectfully. Explain technical disagreements with examples and
evidence, welcome questions, and respect contributors' time and experience.

Harassment, threats, discriminatory abuse, and publishing another person's private
information are not acceptable. Maintainers may remove disruptive content and
restrict repeated misconduct.

Report concerns to the project maintainer through a private repository channel
when available. If a private channel is not available, request one without posting
personal or sensitive details. These expectations apply to project issues, pull
requests, and other project-managed discussions.
